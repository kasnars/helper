# Helper v2 需求清单

本文档是 v2 新增能力的验收基线。所有功能必须在浏览器内完成，数据留在本地。除汇率接口外，不允许调用其它网络服务；汇率接口失败时必须能离线继续使用。

## 1. Cron 表达式解析

- 支持 5 字段（分 时 日 月 周）和 6 字段（秒 分 时 日 月 周）。
- 支持 `*`、`?`、列表、区间、步长，以及月份、星期的英文缩写。
- 用简体中文说明规则含义。
- 给出接下来 10 次运行时间；日与星期同时被限制时按标准 Cron 的“或”关系计算。
- 非法表达式给出明确错误，不展示伪造的时间。

## 2. JWT 解码与校验

- 解码 header 与 payload，并以可读本地时间展示 `exp`、`iat`、`nbf`。
- 根据 `exp` 标出已过期，根据 `nbf` 标出尚未生效。
- 使用 Web Crypto 校验 HS256、HS384、HS512 签名；密钥错误或算法不是这三种时给出原因。
- 解码过程不把 token 发往服务器。

## 3. URL 工具

- 对文本做 URL 编码和解码，非法编码有错误提示。
- 解析完整 URL 的协议、主机、端口、路径、锚点。
- 查询参数以可编辑表格展示，增删改后能重新拼出 URL。

## 4. 文本对比

- 支持行级差异。
- 对改动行做词级或字符级差异。
- 提供并排和行内两种视图。
- 统计新增、删除和修改行数。

## 5. SQL 与代码格式化

- SQL 使用 `sql-formatter`，可选常见数据库方言。
- JS、TS、CSS、HTML、JSON、Markdown、YAML 使用 Prettier standalone，并按需加载解析器。
- 格式化失败时展示错误信息。

## 6. Mock 数据

- 可粘贴 TypeScript interface 或 JSON 示例。
- 使用 `@faker-js/faker` 生成 N 条记录，可选 `zh_CN` 与英文。
- 可导出 JSON 和 CSV。

## 7. Markdown 编辑器

- 左侧编辑、右侧实时预览。
- 支持 mermaid 代码块，库按需加载。
- 可下载 HTML，并可通过打印导出 PDF。

## 8. curl 转代码

- 解析常见 curl：方法、URL、请求头、请求体、基本认证、续行反斜杠。
- 输出 fetch、axios 和 Node.js（全局 fetch）代码。
- 无法识别的参数给出错误，而不是悄悄丢掉。

## 9. 调色板生成

- 由一个基色生成由浅到深的色阶。
- 可复制 CSS 变量和 Tailwind 配置片段。
- 颜色工具中可以跳转到本工具。

## 10. CSS 生成器

- 可视化编辑 box-shadow、linear-gradient、border-radius、cubic-bezier。
- 有即时预览，可复制对应 CSS。

## 11. SVG 优化

- 使用 SVGO 的浏览器构建进行优化，失败时保留原有轻量优化。
- 预览优化结果，并输出 Vue 单文件组件模板。

## 12. 图标 / Favicon

- 上传图片后导出多种尺寸 PNG。
- 打包为 zip，并包含 web manifest。

## 13. 图片裁剪与水印

- 保留并可用现有裁剪工具。
- 水印支持文字和图片，可下载结果。

## 14. EXIF 查看与清除

- 展示拍摄信息和 GPS。
- 下载去掉元数据的副本；JPEG/PNG 直接剔除元数据段，其它格式用画布重编码。

## 15. 长图拼接

- 支持纵向和横向拼接多张图片，并可下载结果。
- 入口位于图片工具中。

## 16. 图片 OCR

- 使用 tesseract.js，默认中文简体加英文。
- 识别引擎和语言包按需加载，不进入首屏包。
- 展示识别文本，可复制。

## 17. 视频转 GIF

- 使用 ffmpeg.wasm 单线程核心，按需加载。
- 可设置开始时间、时长、帧率和宽度。
- 缺少 SharedArrayBuffer 时仍走单线程核心；加载失败时给出明确说明，而不是白屏。

## 18. 番茄钟

- 可开始、暂停、重置工作与休息计时。
- 当天复盘笔记保存在本地。
- 展示本周专注分钟数。

## 19. 记账本

- 可记录金额、分类、日期和备注。
- 按分类展示汇总。
- 支持 CSV 导入和导出。

## 20. 倒计时与纪念日

- 可保存多个日期。
- 未来日期显示剩余天数，过去日期显示已经过的天数。

## 21. 个税与房贷

- 工资薪金按现行累计预扣法计算，展示税率、累计税额和当月应扣。
- 房贷支持等额本息和等额本金，并给出还款计划。

## 22. AI 接口费用

- 内置可编辑的模型价格表，单位为每百万 token 的输入价和输出价。
- 输入 token 数后对比各模型费用，价格保存在本地。

## 23. 单位与汇率

- 单位换算覆盖长度、重量、温度、面积、体积、速度、时间和数据量。
- 汇率优先请求免费公开接口，成功后缓存；失败时使用缓存，再失败时使用内置估算并标明来源。

## 24. 命令面板

- `Cmd/Ctrl + K` 打开。
- 对全部旧工具和新工具做模糊搜索。
- 支持上下键和回车跳转。

## 25. 收藏与最近使用

- 每个工具可收藏。
- 首页和命令面板展示收藏与最近使用。
- 菜单、首页、面板和收藏使用同一份工具注册表。

## 26. PWA

- 可安装，含名称、图标和 manifest。
- 静态资源可离线访问；体积很大的 wasm 与语言包不进入预缓存。

## 27. 全量备份

- 将 IndexedDB 与 `helper_` 前缀的 localStorage 导出为一个 JSON 文件。
- 导入时校验应用名、版本和数据结构，校验失败不覆盖现有数据。
