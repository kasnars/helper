# 调色板

## 功能概述
从一个基色生成 50 到 950 的明暗色阶，导出 CSS 变量和 Tailwind 配置片段。颜色工具里有入口跳到这里。

## 关键技术栈
- `src/lib/color.ts`
- 浅色阶混白色，深色阶混黑色，500 为基色

## 关键组件
- `PaletteGenerator.vue`
- `ColorTool.vue` 上的「生成色阶」

## 实现思路
输入规范为 `#RRGGBB`。`scaleToCss` 输出 `--brand-500` 这类变量，`scaleToTailwind` 输出可粘贴的配置。原有的和谐色搭配仍然保留。

## 功能总结
给一套界面定色时，直接拿到能贴进样式表的变量。
