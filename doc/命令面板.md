# 命令面板与收藏

## 功能概述
按 Ctrl+K 或 Cmd+K 打开命令面板，模糊搜索全部工具并跳转。收藏和最近使用出现在首页和面板顶部。

## 关键技术栈
- `src/tools/registry.ts` 是菜单、首页、面板和收藏的同一份工具表
- Pinia `usage` store，键 `helper_favorites`、`helper_recent`

## 关键组件
- `CommandPalette.vue`
- `ToolPage.vue`
- `src/tools/navigate.ts` 的 `openTool`

## 实现思路
每个工具有 id、名称、关键词、图标、所属页面和懒加载函数。打开工具时写入 sessionStorage、记一次最近使用，再跳到对应路由。方向键移动选择，回车打开。

## 功能总结
工具变多之后，用键盘直接进到要开的那一个。
