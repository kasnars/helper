# AI 费用估算

## 功能概述
按每百万 token 的输入价和输出价，比较多个模型这次调用大概花多少。价格表可以改，并记在本机。

## 关键技术栈
- `src/lib/cost.ts`
- localStorage 键 `helper_ai_prices`

## 关键组件
- `AiCostCalculator.vue`

## 实现思路
费用 = 输入 token / 1e6 × 输入单价 + 输出 token / 1e6 × 输出单价。结果按费用从低到高排。默认含常见模型，可以删掉或加一行。单价没有币种换算，和你填写的单位一致。

## 功能总结
换模型前先看一眼价差。价格会过时，以各厂商当时的标价为准。
