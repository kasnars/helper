# curl 转代码

## 功能概述
把一条 curl 命令转成浏览器 `fetch`、axios 和 Node 18 `fetch` 三份代码。

## 关键技术栈
- `src/lib/curl.ts` 自写分词，处理引号和反斜杠续行

## 关键组件
- `CurlConverter.vue`

## 实现思路
识别 `-X`、`-H`、`-d`、`-u`、`--url`、`-A`。`-k`、`-L`、`-s`、`--compressed` 等不影响请求体的旗标会被忽略。只有请求体、没有方法时按 POST。无法识别的旗标直接报错，避免生成看起来能跑、实际丢了参数的代码。

## 功能总结
从终端命令抄到前端请求时少改一层。
