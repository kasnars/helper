# Cron 解析

## 功能概述
把 5 段或 6 段 Cron 表达式翻译成中文，并列出接下来 10 次运行时间。日和星期同时被限制时按「满足任意一个」计算。

## 关键技术栈
- Vue 3 Composition API
- 纯函数 `src/lib/cron.ts`，不依赖 cron 库
- Element Plus 输入框与标签

## 关键组件
- `CronGenerator.vue`：表达式输入、可视化拼装、常用模板
- `describeCron` / `nextCronRuns`：说明文字和下一次时间

## 实现思路
支持星号、列表、区间、步长，以及月份和星期的英文缩写。`?` 与 `*` 同等。星期 7 归一成 0。从给定时间的下一秒开始找，遇到不匹配的字段直接跳到下一个可能值，并设上限避免死循环。

## 功能总结
适合核对定时任务会不会在预期的工作日触发。表达式非法时页面显示原因，不列出时间。
