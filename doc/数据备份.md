# 数据备份

## 功能概述
把 IndexedDB 和所有 `helper_` 开头的 localStorage 收成一个 JSON 文件。恢复前先校验结构和类型，通过后才覆盖本地数据。

## 关键技术栈
- `src/lib/backup.ts`
- Dexie 事务

## 关键组件
- `DataBackup.vue`

## 实现思路
备份版本为 1，必须带 `app: helper`、导出时间和各表数组。表内记录必须是对象，localStorage 的值必须是字符串。`pomodoroDays` 在旧文件里可以缺省，恢复时当作空表。校验失败不会写入。

## 功能总结
换浏览器或清站点数据之前，先下一份备份。
